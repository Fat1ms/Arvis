# Python 3.13 и PyAudio

На Windows PyAudio часто не имеет стабильных готовых wheel под Python 3.13, из‑за чего голосовой ввод (STT) и wake word могут не работать.

## Рекомендованный вариант
- Используйте Python **3.11** или **3.12** для Arvis.
- Затем запустите `INSTALL.bat` (создаст venv и поставит зависимости).

## Если вы уже на 3.13
Варианты (от лучшего к худшему):
- Переустановить Python 3.11/3.12 и пересоздать venv.
- Попробовать `pipwin install pyaudio` (иногда есть предсобранные колёса).
- Поставить wheel вручную с https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio (если есть подходящий под вашу версию).
- Отключить голосовые функции и работать только с текстом.

## Что ломается без PyAudio
- Голосовой ввод (STT)
- Wake word detection

Текстовый чат, LLM и TTS при этом могут работать нормально.
