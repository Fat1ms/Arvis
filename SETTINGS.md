Этот файл описывает функции и параметры, которые должны быть доступны в меню настроек Arvis. Он служит как техническая спецификация для разработчиков и тестировщиков.

## 1️⃣ Общие настройки (General Settings)

### 1.1 Язык интерфейса
- **Функция:** `set_interface_language(lang_code)`
- **Тип:** Выпадающий список / Комбобокс
- **Параметры:** `ru` (Русский), `uk` (Украинский), `en` (English)
- **По умолчанию:** `en`
- **Описание:** Изменяет язык всех элементов интерфейса и голосовых ответов
- **UI:** Требует перезагрузки приложения

### 1.2 Тема оформления
- **Функция:** `set_theme(theme_name)`
- **Тип:** Радиокнопки / Выпадающий список
- **Параметры:** `light` (Светлая), `dark` (Темная), `system` (Системная)
- **По умолчанию:** `system`
- **Описание:** Переключает визуальную тему приложения (светлая/темная)
- **UI:** Применяется сразу (без перезагрузки)

### 1.3 Автозапуск при входе в систему
- **Функция:** `toggle_autostart(enabled: boolean)`
- **Тип:** Чекбокс
- **Параметры:** Включено / Отключено
- **По умолчанию:** Отключено
- **Описание:** Автоматически запускает Arvis при входе в Windows
- **Файл конфига:** Windows Registry или `startup` папка

### 1.4 Минимизация в трей при запуске
- **Функция:** `toggle_minimize_on_startup(enabled: boolean)`
- **Тип:** Чекбокс
- **По умолчанию:** Отключено
- **Описание:** Приложение запускается свернутым в системный трей

### 1.5 Показывать уведомления
- **Функция:** `toggle_notifications(enabled: boolean)`
- **Тип:** Чекбокс
- **По умолчанию:** Включено
- **Описание:** Показывать всплывающие уведомления (требует, напоминания и т.д.)

## 2️⃣ Голос и распознавание (Voice & Recognition)

### 2.1 Микрофон (для распознавания)
- **Функция:** `set_input_device(device_id: str)`
- **Тип:** Выпадающий список
- **Параметры:** Автоматически заполняется из доступных USB/встроенных микрофонов
- **По умолчанию:** Микрофон по умолчанию системы
- **Описание:** Выбор микрофона для распознавания речи
- **При изменении:** Приложение тестирует микрофон

### 2.2 Чувствительность микрофона
- **Функция:** `set_microphone_sensitivity(level: int)`
- **Тип:** Слайдер (0-100)
- **По умолчанию:** 75
- **Описание:** Регулирует пороговое значение для начала записи
- **Примечание:** Низкое значение = более чувствителен (может ловить шумы)

### 2.3 Модель распознавания (Vosk)
- **Функция:** `set_vosk_model(model_path: str)`
- **Тип:** Выпадающий список
- **Параметры:** Список установленных моделей (например, `vosk-model-ru-0.42` или `vosk-model-en-us-0.42`)
- **По умолчанию:** Стандартная модель для выбранного языка
- **Описание:** Позволяет пользователю выбрать модель распознавания речи
- **UI:** Кнопка загрузки новых моделей

### 2.4 Язык распознавания
- **Функция:** `set_vosk_language(lang_code: str)`
- **Тип:** Выпадающий список
- **Параметры:** `ru` (Русский), `uk` (Украинский), `en` (English)
- **По умолчанию:** Совпадает с языком интерфейса
- **Описание:** Язык для распознавания голоса

### 2.5 Голос ассистента (синтез речи)
- **Функция:** `set_assistant_voice(voice_name: str)`
- **Тип:** Выпадающий список
- **Параметры:** 
  - `bark` - Основной голос (качественный, естественный)
  - `silero` - Запасной голос (более быстрый, менее ресурсоемкий)
- **По умолчанию:** `bark`
- **Описание:** Выбор голоса для ответов Arvis
- **Примечание:** Можно прослушать образец перед выбором

### 2.6 Громкость ассистента
- **Функция:** `set_assistant_volume(level: int)`
- **Тип:** Слайдер (0-100)
- **По умолчанию:** 70
- **Описание:** Громкость ответов Arvis (независимо от системной громкости)

### 2.7 Скорость речи ассистента
- **Функция:** `set_speech_speed(multiplier: float)`
- **Тип:** Слайдер (0.5-2.0)
- **По умолчанию:** 1.0
- **Описание:** Скорость воспроизведения ответов (0.5x - медленно, 2.0x - быстро)

### 2.8 Тон голоса
- **Функция:** `set_voice_pitch(pitch: float)`
- **Тип:** Слайдер (0.8-1.5)
- **По умолчанию:** 1.0
- **Описание:** Изменение тона голоса (1.0 - нормально, <1 - ниже, >1 - выше)

## 3️⃣ ИИ и модели (AI & Models)

### 3.1 Адрес сервера Ollama
- **Функция:** `set_ollama_host(url: str)`
- **Тип:** Текстовое поле
- **Параметры:** URL-адрес (например, `http://127.0.0.1:11434`)
- **По умолчанию:** `http://127.0.0.1:11434`
- **Описание:** Указывает, где запущен сервер Ollama
- **Проверка:** Кнопка "Проверить подключение"

### 3.2 Выбор модели Ollama
- **Функция:** `set_ollama_model(model_name: str)`
- **Тип:** Выпадающий список
- **Параметры:** Динамически заполняется через API Ollama
- **Примеры:** `llama2`, `mistral`, `neural-chat`, `openchat`
- **Описание:** Позволяет пользователю выбрать активную локальную модель для генерации ответов
- **UI:** Показывает список доступных моделей и размер каждой

### 3.3 Параметры генерации
- **Функция:** `set_generation_params(params: dict)`
- **Тип:** Расширяемая опция (показывается при нажатии "Дополнительно")
- **Параметры:**
  - `temperature` (0.0-2.0) - влияет на случайность ответов
  - `top_p` (0.0-1.0) - ядро-выборка для разнообразия
  - `top_k` (1-100) - выбор из топ-K токенов
- **По умолчанию:** `temperature=0.7`, `top_p=0.9`
- **Описание:** Продвинутые параметры для тонкой подстройки поведения модели

### 3.4 Контекстное окно
- **Функция:** `set_context_window(size: int)`
- **Тип:** Слайдер / Поле ввода
- **Параметры:** 512 - 32768 (зависит от модели)
- **По умолчанию:** 2048
- **Описание:** Количество токенов в истории для контекста

## 4️⃣ Интеграции и сервисы (Integrations & Services) - Premium Only 🔒

### 4.1 Google API
- **Функция:** `connect_google_account()`
- **Тип:** Кнопка "Подключить Google"
- **Описание:** OAuth2 авторизация для Gmail и Google Calendar
- **Статус:** Показывает, подключен ли аккаунт
- **UI:** Кнопка "Отключить" если уже подключено

### 4.2 Microsoft Outlook
- **Функция:** `connect_microsoft_account()`
- **Тип:** Кнопка "Подключить Microsoft"
- **Описание:** OAuth2 авторизация для Outlook и Microsoft Calendar
- **Статус:** Показывает, подключен ли аккаунт
- **UI:** Кнопка "Отключить" если уже подключено

### 4.3 VS Code интеграция
- **Функция:** `enable_vscode_integration(enabled: boolean)`
- **Тип:** Чекбокс
- **По умолчанию:** Включено (если VS Code установлена)
- **Описание:** Активирует расширение Arvis в VS Code
- **UI:** Кнопка "Перейти к расширению"

### 4.4 Другие IDE
- **Функция:** `enable_ide_integration(ide_name: str, enabled: boolean)`
- **Тип:** Список чекбоксов
- **Поддерживаемые IDE:** IntelliJ IDEA, PyCharm, Sublime Text, Vim
- **Описание:** Активирует интеграцию Arvis с выбранными IDE

## 5️⃣ Аккаунт и данные (Account & Data) - Premium Only 🔒

### 5.1 Профиль пользователя
- **Функция:** `get_user_profile()`
- **Тип:** Информационная панель
- **Описание:** Показывает:
  - Email
  - Дату регистрации
  - Текущий план подписки
  - Дату окончания подписки

### 5.2 Управление подпиской
- **Функция:** `manage_subscription()`
- **Тип:** Кнопка / Панель
- **Описание:** Переход на портал управления подпиской для:
  - Изменения плана (Free → Premium)
  - Отмены подписки
  - Обновления платежных данных
  - История платежей

### 5.3 Сохранение предпочтений
- **Функция:** `toggle_save_preferences(enabled: boolean)`
- **Тип:** Чекбокс
- **По умолчанию:** Отключено
- **⚠️ Внимание:** Пользователь должен явно разрешить сохранение данных
- **Описание:** Позволяет Arvis сохранять на сервере:
  - Предпочтения и стили общения
  - Часто используемые команды
  - Персональные данные (при согласии)
- **GDPR:** Ссылка на политику конфиденциальности

### 5.4 История диалогов
- **Функция:** `get_cloud_history()`
- **Тип:** Информационная панель
- **Описание:** 
  - Список последних диалогов в облаке
  - Кнопка "Экспортировать все диалоги"
  - Кнопка "Удалить всю историю"
  - Статистика: кол-во сообщений, дата последнего разговора

### 5.5 Экспорт данных (GDPR Right to Data)
- **Функция:** `export_user_data()`
- **Тип:** Кнопка
- **Описание:** Скачивание всех личных данных пользователя в формате JSON
- **Формат:**
  ```json
  {
    "user": {...},
    "conversations": [...],
    "preferences": {...}
  }
  ```

### 5.6 Удаление аккаунта (GDPR Right to Erasure)
- **Функция:** `delete_account()`
- **Тип:** Кнопка (красная, с предупреждением)
- **Описание:** Необратимое удаление всех данных пользователя
- **Подтверждение:** Требует 2-фактор верификации или кода из email
