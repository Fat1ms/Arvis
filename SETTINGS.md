## 4️⃣ Управление API-ключами (API Key Management)

### 4.1 Ключ GNews API
- **Функция:** `set_gnews_api_key(api_key: str)`
- **Тип:** Текстовое поле (скрытый ввод)
- **Описание:** Позволяет ввести API-ключ для доступа к новостному сервису GNews.
- **UI:** Кнопка "Проверить ключ".

### 4.2 Ключ SerpAPI
- **Функция:** `set_serpapi_api_key(api_key: str)`
- **Тип:** Текстовое поле (скрытый ввод)
- **Описание:** Позволяет ввести API-ключ для доступа к веб-поиску через SerpAPI.
- **UI:** Кнопка "Проверить ключ".

---

## 5️⃣ Приватность и безопасность (Privacy & Security)

### 5.1 Логирование диагностики
- **Функция:** `toggle_diagnostic_logging(enabled: boolean)`
- **Тип:** Чекбокс
- **По умолчанию:** Включено (только локально)
- **Описание:** Сохранение логов ошибок локально для диагностики проблем.

### 5.2 Отправка отчетов об ошибках
- **Функция:** `toggle_crash_reports(enabled: boolean)`
- **Тип:** Чекбокс
- **По умолчанию:** Включено
- **Описание:** Отправка анонимных отчетов об ошибках для улучшения приложения.

### 5.3 Проверка обновлений
- **Функция:** `toggle_auto_updates(enabled: boolean)`
- **Тип:** Чекбокс
- **По умолчанию:** Включено
- **Описание:** Автоматическая проверка и установка обновлений.
