Арвис (описание проекта)

Арвис - это персональный помошник, задача которого это поддерживать пользователя в его жызни.

Функционал(текуший) -
- авто запуски ЛЛМ(через оллама)
- ТТС (Silero(запасной)Bark(основной))
- СТТ (Vosk)
- Api (Погода,новости)
- Запуск програю\сайтов (вроде присутствует, но реализация не нравится)
- Текстовый чат
-

Функционал(в планах) -
- Для платных пользователей подключение к серверу для обработки запросов
- Сохранение предпочтений
- История диалогов в облаке
- Кодовый ассистент
- Работа с почтой
- Напоминания и задачи
- Распознавание изображений
- Лайв режым (gemma 2b + ТТС с быстрой генерацией)
