# 🚀 Дорожная карта Arvis: От MVP к финальному продукту

Этот документ описывает план развития проекта Arvis, разделенный на четыре основных этапа, с целью вывести его на рынок как коммерческий продукт с региональной ориентацией на Украину и Европу.

**Статус проекта:** 🟡 В разработке (переход на Qt6 в процессе)  
**Целевой регион:** Украина, Европа  
**Языки:** Русский, Украинский, Английский

---

## Этап 2: Premium-Функции и Монетизация (3-9 месяцев)

**Цель:** Разработать платные функции и бэкенд для их поддержки.

**Приоритет функций для монетизации:**
1. Кодовый ассистент (высокий спрос среди разработчиков)
2. Работа с календарем, почтой, напоминаниями
3. Распознавание изображений (долгосрочно)
4. Погода, новости (Придел бесплатных запросов, при разширении покупка платных API)
5. **Система "Распределения нагрузки" (LDS - Load Distribution System)** ⚙️ **В РАЗРАБОТКЕ**
   - **Концепция:** Пользователи предоставляют свои вычислительные ресурсы (RAM, CPU, GPU) для обработки задач других пользователей, получая виртуальные кредиты. Система распределяет LLM-запросы между провайдерами, формируя общий пул мощностей.
   - **✅ Проделано:**
     * MVP Backend полностью реализован (FastAPI, 10 эндпоинтов)
     * База данных (PostgreSQL): 8 таблиц с полными связями
     * Система аутентификации по API-ключам
     * Виртуальные кредиты и транзакционный учёт
     * Docker-композиция (API + PostgreSQL + Redis)
     * Роли: Consumer (отправка задач) и Provider (обработка)
     * 7/10 интеграционных тестов успешно проходят
   - **⏳ В процессе:**
     * Доработка 3 оставшихся эндпоинтов (Task Status, Provider Earnings, Transaction History)
     * Тестирование безопасности и изоляции (cgroups, seccomp)
     * Prometheus/Grafana мониторинг
   - **📋 Предстоит:**
     * Разработка Executor (изолированный контейнер для выполнения задач)
     * Система безопасности (sandbox, rate limiting, валидация входных данных)
     * Production deployment (OVH VPS, TLS, домен)
     * Интеграция с Arvis-Client
     * Beta-тестирование с реальными пользователями
   - **Доступ:** Платная функция, отдельная подписка Premium+

**Задачи:**
*   **Распространение**
    * Создание красивого Readme для гитхаб с использование изображений интерфейса 
    * Расмотреть возможности распространения Арвис (на данный момент это репозиторий гитхаб)

*   **Клиентская часть (Arvis-Client):**
    *   🔒 Реализация функции "Кодовый ассистент" (подобие Copilot VScode).
    *   🔒 Интеграция с Google API / Microsoft Graph для работы с календарем, почтой, напоминаниями.
    *   🔒 Разработка интерфейсов для новых премиум-функций и админ-функций.
    *   🔒 Реализация системы входа и выхода из аккаунта.
    *   🔒 Сохранение предпочтений пользователя на сервере.

*   **Серверная часть (Arvis-Server):**
    *   🔐 Разработка API для премиум-функций.
    *   🔐 Интеграция с платежной системой (Stripe / LiqPay).
    *   🔐 Система управления подписками (Free → Premium).
    *   🔐 Логирование и аудит действий пользователей (для GDPR).
